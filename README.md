# plantcomNGPN (branch `bh-dev`)

## Description

*Work in Progress* R package for importing, compiling, and querying Northern Great Plains Network (NGPN) plant community monitoring data as collected in the FFI database. The current working version is the `kbh-dev` branch of the [`plantcommNGPN` repository](https://github.com/KateMMiller/plantcomNGPN/tree/kbh-dev)


## Instructions

Instructions on using the package are found [here](https://katemmiller.github.io/plantcomNGPN/)
